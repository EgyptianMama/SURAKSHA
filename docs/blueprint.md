# **App Name**: Suraksha Sathi

## Core Features:

- Blueprint Analysis and Hazard Instructions: Analyzes uploaded school blueprints and provides hazard-specific evacuation instructions.
- Voice Navigation Guidance: Provides spoken turn-by-turn guidance based on generated evacuation routes.
- Video Training Library: Presents categorized emergency training videos to users. Includes user progress tracking and photo uploads upon drill completion.
- User Role Display: Shows/hides UI elements and options based on user role. Uses dummy roles rather than real authentication.
- Emergency Notification Broadcaster: Sends simulated emergency notifications through multiple channels to demonstrate broadcast ability.
- Geospatial Impact Tool: Given a location and type of incident, predict related regional impacts using an AI tool.

## Style Guidelines:

- Primary color: HSL values indicate a teal leaning toward green (#45A094) for calm and safety.
- Background color: Off-white/light gray (#F0F0F0) to provide a clean, neutral backdrop.
- Accent color: Soft orange (#E59443) to highlight important actions.
- Headline font: 'Space Grotesk' sans-serif for a modern, technical look.
- Body font: 'Inter' sans-serif for readability.
- Use clear, understandable icons sourced from Heroicons to represent different functions and emergency types.
- Design a simple grid-based layout that adapts to different screen sizes.
